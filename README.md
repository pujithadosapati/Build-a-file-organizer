## Build a File Organizer Using Python
## Project Description
The File Organizer is a Python automation project that scans a specified folder and automatically organizes files into separate folders based on their extensions.
## Objective
To learn filesystem automation using Python and reduce the time required for manual file organization.
## Technologies Used
- Python 3
- pathlib
- os
- shutil
## Features
- Automatically scans a folder.
- Identifies files based on their extensions.
- Creates folders automatically.
- Moves files into their respective folders.
- Handles duplicate filenames safely.
- Organizes unknown file types into an Others folder.
## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Create a folder named "Test_Files".
4. Add sample files to the folder.
5. Run the following command:
Buld_a_file_organizer.py
## Expected Result
Files are automatically moved into separate folders according to their extensions.
## Libraries Used
- pathlib: For handling file and folder paths.
- shutil: For moving files between folders.
- os: For operating-system-related file operations.
## Conclusion
This project demonstrates how Python can automate repetitive file-management tasks and organize files efficiently.
